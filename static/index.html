首次安装与启动说明
  1. 在项目目录中打开终端，安装依赖。
    python -m pip install -r requirements.txt
  2. 启动本机服务，保持终端打开。
    python server.py
  3. 在浏览器打开 http://127.0.0.1:8000，填入密钥后点击「保存并验证」。

Windows 也可双击 start.cmd 启动。

使用环境变量配置密钥

可在启动前设置 ALPHA_GENOME_API_KEY。页面清除只影响当前进程与本地密钥文件，不会修改系统环境变量；重启后可能再次加载。
